# Cinco imágenes de muestra: pase exploratorio autorizado

El usuario autorizó continuar con las cinco imágenes restantes, sin aportar una sexta. Antes de cada llamada se congelaron localmente hash de imagen, prompt, modelo solicitado, esfuerzo y criterio. Cada imagen recibió una única solicitud Codex CLI a `gpt-6-luna` medium, sin límite breve de tiempo ni reintento automático. El protocolo íntegro está en `target/mcp-cli-development/five-sample-protocol-frozen.md` y los manifiestos/prompts privados bajo el mismo árbol; el código verifica su hash. Las imágenes originales permanecen en Downloads y ningún archivo de muestra entra en Git.

El primer pase produjo **3/5 geometrías acotadas verificadas**, un fallo métrico y una abstención explícita. Los tres casos positivos pasaron PlanSpec, CAD GUI aislado, guardado DWG, captura PNG, cierre limpio y AutoCAD Core Console: `AUDIT` 0/0, unidades métricas, cuatro LINE y coincidencia de cuatro handles/extremos por caso a `1e-6`. Un caso escogió otra cota horizontal visible porque el prompt no distinguía dos valores; el criterio previo se conservó y el caso falló sin CAD. El otro respondió `UNSUPPORTED` y no generó CAD. Las capturas muestran solo las regiones rectangulares pedidas, no planos completos.

`summarize_cli_samples.py` revalida fuente, prompt, protocolo, JSONL, evidencia CAD anidada, AutoCAD y conteo; el resultado está en `target/mcp-cli-development/five-sample-summary-v3.json`, SHA-256 `5D3CA19584EB8A91BD263961B3B34831EC5F0C9E7325D90DD462749F58F270B4`. La fotografía de alta resolución dejó `region_px` probablemente relativos a una vista reducida; esa procedencia espacial no está verificada. Ni el modelo efectivo, ni tokens directos del proveedor, ni supervisor, ni calidad de lámina completa, ni L5 humano se acreditan. Los cinco casos son desarrollo; el experimento reservado baseline/candidato de M7 sigue pendiente.
