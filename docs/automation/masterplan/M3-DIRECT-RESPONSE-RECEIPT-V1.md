# M3 — recibo de respuesta directa v1

La [ficha oficial de GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) confirma el identificador `gpt-6-luna` y el uso de Responses API. El [esquema oficial de respuesta](https://developers.openai.com/api/reference/cli/resources/responses/methods/create) expone `id`, `model`, `status` y `usage`, incluidos `cached_tokens`, `cache_write_tokens` y `reasoning_tokens`.

`provider_response_receipt.from_response` acepta en memoria un objeto JSON de respuesta `completed`, valida identidad y aritmética completa de uso, y emite solo hashes de ID/objeto, modelo y seis contadores. Nunca guarda prompt, imagen, salida, ID de respuesta ni credenciales. `Observation.generator_response` y `supervisor_response` son opcionales; si se aportan, `reserved_runner.run_once` exige que ID, modelo y uso declarados coincidan con los objetos directos. Una contradicción o respuesta incompleta consume la casilla como `uncertain`, sin reintentar. El sobre sellado guarda los recibos sanitizados y `usage_provenance=adapter_supplied_direct_response_objects`; `verify_envelope` los vuelve a cotejar con los contadores y el modelo al reabrir.

**Límite de confianza:** los objetos llegan a través del adaptador inyectado. Este código no llama a la API, no autentica criptográficamente la respuesta ni confirma que un callback no haya fabricado el objeto o reintentado por dentro. Por eso `inspect_slot` mantiene G0–G10 `pending`; el recibo mejora trazabilidad L0, no otorga identidad/eficiencia aprobadas. Para M3/M7 real falta un adaptador de Responses API que haga una sola creación por casilla reservada, registre el objeto directo de Luna y el supervisor, complete CAD y aporte evidencia externa. En este host no se encontró `OPENAI_API_KEY` ni `CODEX_API_KEY` configurada al corte; no se hizo ninguna solicitud real. No se publican claves ni valores de entorno.

Reproducir L0: `python -m unittest discover -s docs/automation/masterplan -p 'test_*.py' -q`. Los fixtures de respuesta son sintéticos. El tratamiento de errores conserva la incertidumbre de una mutación CAD posible.
