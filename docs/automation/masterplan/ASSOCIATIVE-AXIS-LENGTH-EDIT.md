# Edición asociativa acotada de longitud de muro

`edit_wall_length` modifica una sola envolvente rectangular de cuatro LINE ordenadas y una cota nativa `Linear` o `Aligned`. Requiere `edge_handles`, `dimension_handle`, `expected_length_m`, `new_length_m`, `expected_thickness_m`, `document_id`, `revision` y `request_id`. El cliente MCP consulta la operación por `request_id` después de una respuesta incierta; reproducir el mismo ID devuelve el resultado registrado sin repetir la mutación. La operación no es un paso de `batch`.

El backend rechaza handles repetidos, capa bloqueada, geometría no finita o fuera de Z=0, contorno abierto, paralelismo/ortogonalidad inválidos, longitud o espesor distintos de los valores esperados y una cota cuya medida o referencias no coincidan. Las referencias de la cota deben apuntar exactamente a los dos remates del muro. El propietario de espacio modelo de esas líneas debe contener solo las cuatro LINE y esa DIMENSION; un elemento adicional bloquea la edición para evitar dejar huecos, puertas, muros unidos u otras cotas desfasados. Las entidades internas del bloque gráfico de la cota tienen otro propietario. El cambio desplaza el remate final por la dirección del eje y conserva el inicial y el espesor. Si falla una actualización o la medida asociativa final, revierte las líneas y elimina la entrada de deshacer; el éxito crea una entrada de deshacer.

Los fixtures v9 de eje horizontal y oblicuo 3–4–5 son la fuente sintética. El arnés `mcp_wall_length_smoke.py` guarda DWG antes y después, comprueba 4→4.5 m y 5→5.5 m, contorno, espesor, cota, reapertura, rechazo de estado obsoleto, consulta de operación y reproducción idempotente. La sonda AutoCAD coteja las cuatro LINE por handle y punto, DXF42 y DIMREF con osnap MID a ambos remates, antes y después. Una copia con referencia esperada adulterada debe rechazarse.

El alcance sigue siendo un solo muro aislado. No cubre múltiples muros, joins, huecos, cotas múltiples, impresión, escala de papel, actualización de topologías dependientes ni revisión humana L5. No se ha abierto ni modificado el DWG privado.
