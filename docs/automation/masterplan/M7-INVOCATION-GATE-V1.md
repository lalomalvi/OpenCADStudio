# M7 — gate de invocación única v1

`reserved_runner.run_once` recibe un `TrialJournal` congelado y una función adaptadora `invoke(Invocation) -> Observation`. La reserva se sincroniza en el journal **antes** de llamar al adaptador. `Invocation` entrega la imagen autorizada, protocolo, binario CAD, modelo y esfuerzo, pero no el oráculo. El adaptador se llama una sola vez. Una excepción o metadatos inválidos después de la reserva consumen la casilla como `uncertain`; no hay reintento automático. Una caída del proceso puede dejar intención pendiente para reconciliación manual con el mismo ID.

La observación del adaptador declara identidad de respuesta/modelo, uso generador/supervisor y ruta de evidencia CAD JSON. `run_once` valida aritmética de tokens, exige que la evidencia resida bajo el directorio del run, guarda solo hashes de IDs y ruta relativa/hash de la evidencia. El sobre se crea de forma exclusiva y se sincroniza antes de `record_result`. `verify_envelope` vuelve a comprobar el archivo CAD referido; debe ejecutarse antes de consumir ese resultado en un evaluador. Una falta de uso supervisor o evidencia CAD deja `partial`, y una identidad de modelo distinta no puede producir `completed`. El campo `gates=unevaluated` es fijo: `completed` solo significa que el adaptador entregó el conjunto de metadatos, no que G0–G10, CAD, L4 o L5 hayan pasado.

La procedencia del uso es `adapter_reported_unverified`. No existe todavía un adaptador conectado a Luna ni una prueba de identidad/uso contra una respuesta directa del proveedor. El callback es una frontera de confianza que debe prohibir reintentos internos ante estado incierto; el wrapper no puede inspeccionar sus efectos internos. Ningún criterio del oráculo se entrega al callback. Las pruebas actuales usan proveedores sintéticos y prueban orden, una sola llamada, incertidumbre, validación, privacidad del sobre y adulteración de evidencia anidada. El run M7 real sigue pendiente de seis imágenes inéditas, oráculos revisados, telemetría directa y G0–G10 independientes.

Reproducción L0: `python -m unittest discover -s docs/automation/masterplan -p 'test_*.py' -q`.
