Fecha: 2026-09-24. Se reutilizaron la misma imagen, el mismo resultado Luna y las 21 líneas parciales del departamento. No hubo nueva llamada al modelo. Los runs v1 y v2 se conservan. La imagen sigue fuera de Git (SHA-256 `0CD0B310FC337C18704B658B41DF49ABB63E2F398893273BBFCFD503B2134057`); el DWG privado no se abrió ni modificó.

PlanSpec v8 asigna las cuatro LINE de referencia a `OCS_DIM_REF`, nunca las 21 líneas arquitectónicas, y ejecuta `LAYER OFF OCS_DIM_REF` después de crear siete cotas nativas. El comando exige capacidad `layer_assignment`. El compilador rechaza una línea arquitectónica en esa capa. Las cotas siguen ligadas a esa referencia técnica; no se afirma asociación con muros reales.
