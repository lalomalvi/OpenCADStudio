# M3/M7 — ejecutor CAD de GUI propia v1

`OwnedCadExecutor` recibe un cliente MCP persistente, un proceso GUI hijo iniciado con `--new-instance`, el binario congelado y un directorio de run absoluto. Verifica hash del binario, PID/ruta/instante del descriptor, ausencia de modal, comando activo y documentos sucios antes de editar. Ejecuta `new`, `run_script` estricto y `save_verified` con IDs derivados de la casilla, usando la conciliación del mismo ID que implementa `Client`. Comprueba cantidad de pasos/entidades, auditoría, reapertura interna y SHA-256 del DWG. Escribe evidencia JSON sin PlanSpec, imagen ni texto de modelo. `verify_owned_cad_evidence` reabre el DWG y coteja bytes/hash; `reserved_runner` lo exige al sellar y verificar el sobre.
